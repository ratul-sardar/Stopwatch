# Stopwatch
This is just a simple stopwatch I made while recovering from dengue.

## Tech used
- React 19 (no react compiler)
- Typescript 7
- Bun (package manager)
- Tailwind v4
- ShadcnUi (base ui, lucid icons)
- Biom.js (for formatting and linting)

## To install run:
```js
bun install
```

## To run dev:
```js
bun run dev
```

## To run build:
```js
bun run build
```

## For linting and formatting run:
```js
bun run lint
```
